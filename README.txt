ВРЕМЕНА ЗА НАМАЗ — как се публикува

1. Качете ВСИЧКИ файлове от тази папка в една и съща папка на сайта
   (например в хранилището за GitHub Pages):
     index.html, sw.js, manifest.webmanifest,
     icon-192.png, icon-512.png, apple-touch-icon.png, favicon.png
   (icon.svg е само източникът на иконата — не е задължителен.)

2. Сайтът трябва да е с https:// (GitHub Pages е така по подразбиране).
   Инсталирането и работата без интернет НЕ работят, ако index.html се отвори
   директно като файл от компютъра.

3. Инсталиране:
   - Android / компютър (Chrome, Edge): Меню → „Инсталирай приложението“
     или бутона „Добави“ в долната част.
   - iPhone / iPad: Safari → „Сподели“ → „Добави към началния екран“
     (приложението показва тези стъпки само).

4. При промяна на index.html: в sw.js сменете VERSION
   (напр. 'namaz-v1' → 'namaz-v2'), за да се обнови при всички.
   Новата версия се показва при следващото отваряне на приложението.
